# Triage labels

Vocabulário das cinco funções canônicas de triagem. Cada string de label é igual ao nome da função — sem override.

| Função | Label |
|---|---|
| Aguardando avaliação | `needs-triage` |
| Aguardando mais informações | `needs-info` |
| Pronto para um agente AFK | `ready-for-agent` |
| Requer implementação humana | `ready-for-human` |
| Não será trabalhado | `wontfix` |
