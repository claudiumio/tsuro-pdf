Cláusula 3ª — Do objeto

O presente contrato tem por objeto a prestação de serviços de leitura e verificação de documentos digitais, incluindo a conferência de assinaturas eletrônicas apostas ao presente instrumento.

O contrato vigorará pelo prazo de 12 (doze) meses, contados da assinatura, renovável por igual período mediante aditivo contratual expresso.

O que reaproveitar

  • SumatraPDF — toolbar presa de uma fileira, modos pinned/overlay/hidden (Customize toolbar).
  • Evince — header bar compacta com página/busca/zoom/menu; campo de página com salto direto (Header bar).
  • Progressive disclosure — só navegação + zoom + busca visíveis; resto vai para “···” quando existir.

Riscos para a missão

  • Nenhum. Mesmos widgets do iced, só reagrupados. Nenhum render, parse ou IO novo no caminho de abrir.

Viabilidade no iced

  • Trivial: o toolbar() atual já é um row! — grupos com separadores, “Página N / total” vira text_input, painel vira condicional a um bool.
