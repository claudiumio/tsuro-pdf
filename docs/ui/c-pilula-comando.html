Cláusula 4ª — Do prazo

O contrato vigorará pelo prazo de 12 (doze) meses, contados da assinatura, renovável por igual período mediante aditivo contratual expresso.

Findo o prazo, o contrato prorroga-se automaticamente, salvo manifestação contrária de qualquer das partes.

Revisão impecável (resumo)

  • Bloqueador resolvido: antes havia dois primários competindo (Abrir preto sólido + pílula). Agora a pílula é o único elemento saturado; Abrir virou ghost — hierarquia com um vencedor.
  • Importante: área de clique ≥36px (zoom e página anterior/próxima miram 40–44px por uso repetido) mesmo com visual de 28–32px; no iced, isso é Button::padding, não botão maior.
  • Importante: leitor de tela não lê glifo — cada botão-ícone precisa de descrição acessível + tooltip imediata; foco de teclado visível.
  • Nitpick: um único peso de traço (Lucide 2px, round caps) em todo o conjunto; nada de misturar estilos.

O que reaproveitar

  • Lucide (licença ISC — pode vendorizar os SVGs em crates/tsuro/assets/icons/): um campo, múltiplas intenções, como Arc/Raycast/VS Code quick-open.
  • Readest — paleta como “válvula de escape” dos comandos (Getting started); Evince — busca inline com contador, sem modal.

Viabilidade no iced (verificado no workspace)

  • iced 0.13.1 (lockfile); iced_widget::svg e tooltip existem nessa versão (conferido no registry local) — falta só habilitar a feature "svg" no crates/tsuro/Cargo.toml (puxa resvg) e trocar cada button("texto") por button(svg(handle)) + tooltip.
  • Nenhum IO/render novo no caminho de abrir: ícones são handles estáticos carregados uma vez — risco zero para a missão.
